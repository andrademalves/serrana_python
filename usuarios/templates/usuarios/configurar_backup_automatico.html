Informações
Como funciona o backup automático:
  • O sistema verifica a cada 5 minutos se chegou o horário de executar o backup
  • Quando o horário definido chega, o backup é gerado automaticamente
  • Backups agendados são executados apenas uma vez por dia/semana/mês
  • A política de retenção é aplicada automaticamente após cada backup
  • Backups protegidos nunca são excluídos automaticamente
Configuração do Cron (apenas para administradores do servidor):

Para que os backups automáticos funcionem, é necessário configurar um cron job no servidor:

*/5 * * * * /root/serrana_python/venv/bin/python /root/serrana_python/manage.py run_scheduled_backups >> /var/log/backup_cron.log 2>&1

Este comando deve ser adicionado ao crontab do usuário root no servidor.
